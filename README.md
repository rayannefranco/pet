# Meu Pet — Vida & Documentos

Página de vendas mobile-first do produto digital **Meu Pet — Vida & Documentos**.

## Estrutura

- `index.html` — estrutura e copy da página
- `css/style.css` — identidade visual e responsividade
- `js/script.js` — interações e preparação do checkout
- `assets/images/` — pasta reservada para mockups, fotos e imagens do produto

## Checkout

Antes de publicar, conecte o botão principal ao checkout real.

Uma forma simples é adicionar no botão:

```html
data-checkout-url="https://SEU-CHECKOUT-AQUI"
```

e trocar o JavaScript para redirecionar para esse endereço, ou substituir diretamente o `href`.

## Observação

Os documentos personalizados do produto são apresentados como materiais organizacionais, informativos e afetivos, sem validade oficial.
